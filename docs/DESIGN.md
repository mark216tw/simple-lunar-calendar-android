# 系統設計文件

本文件說明「簡單農民曆」的功能設計、資料模型、畫面結構與互動規則。若需了解技術分層與建置方式，請參閱 [系統架構與技術文件](ARCHITECTURE.md)。

## 1. 設計目標

1. **一眼可讀**：開啟即見今日資訊，重要數字（日期）以大字呈現。
2. **操作單純**：少量頁面、單層導覽，設定即時生效。
3. **離線可靠**：不依賴網路，資料內建。
4. **在地化**：繁體中文、台灣用語與曆法、台灣神明生日。
5. **一致視覺**：暖色系主題、淺色／深色一致體驗。

## 2. 資訊架構

```text
首頁（TODAY）
 ├─ 日期（可點選開啟日期選擇器）
 ├─ 星期與農曆日期
 ├─ 前一天 / 回到今天 / 後一天
 ├─ 節氣與節日
 └─ 神明生日（可點「查看全部」進入清單）
月曆（CALENDAR）
 ├─ 上／下個月、年月選擇、回到本月
 ├─ 星期列與 6×7 月曆格線
 └─ 點選日期回首頁顯示當日詳細（西元、農曆、節氣、節日）
神明生日清單（DEITIES）
 └─ 依農曆月份分組列出全部神明生日
設定（SETTINGS）
 ├─ 顯示模式（系統 / 淺色 / 深色）
 └─ 主題色彩（六種預設 + 自訂色相）
```

導覽採單一 Activity 的畫面狀態切換：首頁右上角月曆與設定圖示分別進入月曆頁與設定頁；神明生日卡片「查看全部」進入清單頁；各頁以返回圖示或系統返回鍵回到首頁。

## 3. 資料模型

### 3.1 `AlmanacDay`（每日資訊）

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `date` | `LocalDate` | 所選西元日期 |
| `lunarDate` | `String` | 農曆日期顯示文字，如「七月廿七」 |
| `lunarMonthLabel` | `String` | 農曆月顯示文字，如「七月」「閏六月」 |
| `lunarDayLabel` | `String` | 農曆日顯示文字，如「廿七」 |
| `festivals` | `List<String>` | 當日節日（去重後） |
| `solarTerm` | `String?` | 所選日期當下最近節氣 |
| `deityBirthdays` | `List<String>` | 當日台灣神明生日（去重後） |

### 3.2 `ThemeSettings`（主題設定）

| 欄位 | 型別 | 預設 | 說明 |
| --- | --- | --- | --- |
| `colorChoice` | `ThemeChoice` | `RED` | 主題色，含 `CUSTOM` |
| `customHue` | `Float` | `350f` | 自訂色相（0–360） |
| `displayMode` | `DisplayMode` | `SYSTEM` | 顯示模式 |

`ThemeChoice` 另帶 `hue` 屬性，用於預設色與自訂滑桿的連動。

### 3.3 神明生日對照

`DeityBirthdays` 以「農曆月 → 農曆日 → 名稱清單」儲存。查詢規則：

- 僅一般月（非閏月）顯示。
- 同一天多筆名稱去重後依建檔順序呈現。
- 名稱僅移除來源標記 `*`，其餘保留原文（含別名與說明）。
- `all()` 回傳全部 `DeityBirthday`（農曆月、日與名稱清單），依農曆月、日排序，供神明生日清單頁使用。

### 3.4 月曆資料

`AlmanacRepository.month(yearMonth)` 回傳 `CalendarMonth`（`year`、`month`、`weeks`）。`weeks` 固定為 6 週 × 7 天、週日起算，前後補齊相鄰月份日期：

| 型別 | 欄位 | 說明 |
| --- | --- | --- |
| `CalendarCell` | `day` | 該格 `AlmanacDay` |
| `CalendarCell` | `inMonth` | 是否屬於查詢月份 |
| `CalendarCell` | `termOnDay` | 當日交節氣的節氣名稱，否則 `null` |
| `CalendarDate` | `date`／`inMonth`／`termOnDay` | 不依賴 ICU 的純格線，供節氣標記與測試 |

`monthDates(yearMonth)` 僅計算格線日期與節氣標記，不存取 ICU，因此可於本機單元測試驗證。

## 4. 曆法與衍生資訊規則

- **農曆**：以 ICU `ChineseCalendar` 取得農曆月、日與閏月旗標；月名（正月…臘月）與日名（初一…三十）由 `LunarNames` 轉換。
- **節氣**：由 `SolarTerms` 以太陽視黃經天文演算法計算，取所選日期當下最近的節氣；月曆格線另以 `termOn` 標示交節氣當日。
- **節日**：包含國曆節日（元旦、和平紀念日、兒童節、國慶日）與農曆節日（春節、天公生、元宵、土地公生、玄天上帝誕辰、媽祖誕辰、浴佛節、端午、七夕、中元、中秋、重陽、臘八、送神、小年夜、除夕），閏月不顯示農曆節日。冬至屬節氣，僅顯示於「節氣」欄。
- **神明生日**：依農曆月日查表，閏月不顯示。
- **月曆格線顯示優先序**：節氣（當日交節氣）→ 節日 → 農曆初一顯示「農曆月名」→ 其餘顯示農曆日名。節氣與節日以主色強調。

## 5. 畫面設計

### 5.1 首頁

- **日期主視覺**：可點選的日期膠囊、超大日期數字、農曆文字。
- **日期切換列**：左「前一天」、中「回到今天」（非今天才顯示）、右「後一天」，全寬左右貼齊。
- **節日與節氣卡**：有資料時並列顯示「節氣」「節日」；無資料顯示「今日無節日與節氣」。
- **神明生日卡**：標題「神明生日」，以標籤（chip）流式排列；無資料顯示「今日無神明生日」。
- **日期選擇器**：Material 3 `DatePickerDialog`，以 UTC 毫秒換算選定日期。

### 5.2 設定

- **顯示模式**：系統、淺色、深色三格橫向排列，圖示加文字，選取以填色與外框表示。
- **主題色彩**：六種暖色預設以兩欄格線排列；下方為「自訂色彩」卡片。
  - 自訂卡片不整片填色，選取時以自訂色邊框與勾選圖示標示。
  - 自訂卡片的圓形色塊與滑桿光點顯示目前所選主題色；點選預設色時滑桿光點跳至該色相，拖曳滑桿即切換為自訂色。

### 5.3 月曆

- **月份列**：左「上個月」、中間可點選的年月膠囊（開啟年月選擇器）、右「下個月」；右上角「回到本月」。
- **年月選擇器**：對話框內以上一年／下一年切換年份，並以 4 欄格線選擇 1–12 月，確定後跳至該年月。
- **格線**：星期列（日 一 二 三 四 五 六，週末以主色標示）與 6×7 格線。
- **日期格**：西元日大字，下方依顯示優先序顯示節氣、節日或農曆日名；今天以圓角外框標示，非本月日期淡化。
- **互動**：點選任一日回首頁並顯示該日詳細；月曆狀態以 `rememberSaveable` 保留。

### 5.4 神明生日清單

- **入口**：首頁「神明生日」卡片標題列右側「查看全部」。
- **呈現**：`LazyColumn`，頂端顯示總筆數，內容依農曆月份分段（月份小標 + 每筆「農曆 M 月 D 日」與神明名稱清單）。
- **互動**：純閱覽，項目不可點擊。

## 6. 主題系統

- **預設色**：喜氣紅、珊瑚粉、蜜桃、莓紅、柑橘橙、暖陽金，皆為暖色系中等亮度，兼顧主色文字對比。
- **自訂色**：以 HSL（飽和度 0.64、亮度 0.43）由色相 0–360 產生，搭配彩虹色相滑桿。
- **深色模式**：主色向白色微調以維持可讀性。
- **系統列**：狀態列與導覽列透明，圖示明暗依明暗主題切換。
- **選取內容色**：依背景亮度自動選擇深或淺文字，確保對比。

## 7. 桌面小工具

- **顯示內容**：標題列（今日農民曆 + 日期）、農曆與節氣、神明生日摘要。
- **神明生日摘要**：當日三筆以內全列；超過三筆顯示前三筆加「等 N 則」。
- **更新時機**：系統定期更新（30 分鐘）、日期／時間／時區變更、開機完成、以及變更主題設定時。
- **點選行為**：點選小工具開啟 APP。

## 8. 狀態與持久化

- `MainViewModel` 為設定的單一真實來源，UI 以 `StateFlow` 訂閱。
- 設定以 DataStore Preferences 非同步保存；變更採樂觀更新，UI 立即反映。
- 自訂色相拖曳具去抖動，降低寫入頻率。
- 設定變更加速刷新桌面小工具。

## 9. 邊界與錯誤處理

- 農曆與節氣皆為即時計算，無資料範圍限制。
- 閏月：不顯示農曆節日與神明生日，避免與一般月重複。
- 節氣演算法誤差極小，僅少數跨午夜交界可能相差一日。
- 未知的主題或顯示模式字串：回退為預設值（`RED`／`SYSTEM`）。

## 10. 無障礙與體驗

- 主要文字採高對比；選取項以填色、外框與圖示多重提示。
- 大字日期與分區標題使用不同層級字重，維持視覺層次。
- 支援淺色、深色與跟隨系統，降低夜間閱讀負擔。

## 11. 未來擴充

- 更多曆法資訊（如沖煞、生肖）或個人化收藏。
- 小工具尺寸與版面客製。
- 單元／UI 測試覆蓋率提升與 CI 自動建置。
