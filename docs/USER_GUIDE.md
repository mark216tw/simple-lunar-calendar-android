# 使用指南

## 安裝測試 APK（Pre-release）

1. 前往 GitHub 專案的 **Releases** 頁面。
2. 找到標示為 **Pre-release** 的版本。
3. 下載 `app-prerelease.apk`。
4. 在 Android 手機開啟 APK。
5. 若系統阻擋安裝，依畫面指示暫時允許該檔案管理器或瀏覽器安裝未知來源應用程式。
6. 安裝完成後，建議立即關閉該來源的「允許安裝未知應用程式」權限。

`app-prerelease.apk` 為測試用的 Pre-release 版本，已啟用 R8 壓縮並使用 Android 開發用金鑰（Debug 金鑰）簽署，只適合測試，並非正式上線版本。

## 查看今日農民曆

開啟「簡單農民曆」後，首頁會自動顯示手機當地日期的農民曆資訊：

- 西元年月日與星期
- 農曆日期
- 目前節氣
- 當日節日
- 台灣神明生日（依農曆日期）

沒有節日時，畫面會顯示「今日無節日與節氣」或僅顯示節氣。神明生日區塊在當日無資料時會顯示「今日無神明生日」。

## 切換日期

- 點選「前一天」或「後一天」逐日切換。
- 點選首頁上方日期可開啟日期選擇器。
- 離開今天後，可點選「回到今天」快速返回。
- 若選擇的日期不在資料範圍內，APP 仍會以 Android ICU 計算並顯示農曆日期。

## 更換主題

1. 點選首頁右上角的設定圖示。
2. 從喜氣紅、珊瑚粉、蜜桃、莓紅、柑橘橙或暖陽金選擇主題。
3. 如需自訂色彩，點選「自訂色彩」並拖曳彩虹色相滑桿。
4. 所有變更會立即呈現在 APP，不需要另外按下儲存。

選擇預設主題色時，「自訂色彩」的圓形色塊與滑桿會同步顯示該色；拖曳滑桿即切換為自訂色彩。

主題設定會保存在手機中，下次開啟 APP 時自動套用。

## 切換顯示模式

設定頁提供以下模式：

- **系統**：預設值，依手機系統設定切換淺色或深色。
- **淺色**：固定使用淺色介面。
- **深色**：固定使用深色介面。

切換後，主介面、狀態列與系統導覽列會立即更新。

## 新增桌面小工具

不同手機品牌的操作可能略有差異，一般步驟如下：

1. 長按 Android 桌面空白處。
2. 選擇「小工具」或「Widgets」。
3. 找到「簡單農民曆」。
4. 長按「今日農民曆」小工具並拖曳至桌面。
5. 視需要調整小工具大小。

小工具會顯示今日日期、農曆、節氣與神明生日。當日神明生日超過三筆時，小工具會顯示前三筆並標示總筆數。點選小工具可開啟 APP。

## 移除 APP

長按 APP 圖示並選擇「解除安裝」，或前往 Android 的「設定 > 應用程式 > 簡單農民曆」解除安裝。
